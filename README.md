# 🎭 Joke Generator

A fun web app for generating random jokes! Built with React and Express.

## ✨ Features

- 🎲 Generate random jokes
- 🏷️ Filter by category (Programming, General, Knock-knock, Dark, Pun, Spooky, etc.)
- 📋 Copy jokes to clipboard
- ⭐ Save favorite jokes
- 🌙 Dark mode toggle
- 💾 Persistent storage (localStorage)

## 🚀 Installation & Setup

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

```bash
npm run install-all
npm start
